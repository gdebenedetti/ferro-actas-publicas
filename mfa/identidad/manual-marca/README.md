# MFA-manual-marca

Espejo local de la carpeta de Drive `12FKsAOXPPVNHwh6cIMs4LmOKo9-kacxI`.

Este directorio guarda el paquete de manual de marca de Movimiento Ferro en Accion / MFA, con el archivo editable comprimido, el PDF de referencia, el informe del paquete y los recursos vinculados que usa el material.

## Contenido

- `movimientoferro-marca.pdf`: manual de aplicaciones y criterios de uso de marca.
- `movimientoferro-marca.ai.xz`: archivo editable original comprimido para mantenerlo dentro de los limites de GitHub.
- `movimientoferro-marca Informe.txt`: informe del paquete con fuentes, enlazados y piezas incluidas.
- `Logos/`: variantes de logo en verde y crema (faltante en el espejo actual; revisar contra Drive).
- `Fonts/`: tipografias del sistema de marca.
- `Links/`: piezas y recursos de referencia usados en el armado del manual.

## Como actualizar desde Drive

1. Abrir la carpeta fuente en Drive y volver a descargar el contenido desde `12FKsAOXPPVNHwh6cIMs4LmOKo9-kacxI`.
2. Reemplazar localmente los archivos manteniendo la misma estructura de carpetas y, si es posible, los mismos nombres.
3. Si Drive suma, elimina o renombra algun recurso, reflejar ese cambio aqui para que el espejo siga siendo trazable.
4. Si cambia el contenido del paquete, volver a sincronizar `pdf`, `ai.xz`, `Informe.txt`, `Fonts/` y `Links/` (y `Logos/` si existe en la fuente Drive).
5. Para recuperar el archivo editable, descomprimir `movimientoferro-marca.ai.xz` con `xz -d -k movimientoferro-marca.ai.xz`.

## Nota de espejo

- Los nombres originales se mantienen para conservar la correspondencia con Drive.
- `Links/` incluye archivos de referencia y exportaciones usadas en el manual; no es un enlace externo ni una carpeta de navegacion.
