## Limitaciones y uso

- El video de X del 25/08 se reprodujo en Chrome, pero sólo expuso una URL `blob:`; se conserva la portada y queda pendiente el MP4 original.
- Para Instagram, el bundler de recursos devolvió `TypeError: Failed to fetch`. La reproducción visible permitió recuperar los rangos DASH directamente; los fragmentos y ensamblados quedan como material local de trabajo, no como publicación automática ni parte del repositorio.
- Las imágenes autorizadas por el usuario pueden evaluarse para reutilización, pero antes de producción hay que definir alt text, créditos, encuadre y si aparecen personas identificables.
- No se descargó ni se inventó material de cuentas personales, comentarios o fuentes sustitutas.
